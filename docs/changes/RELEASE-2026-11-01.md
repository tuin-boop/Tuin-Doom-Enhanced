# November 1, 2026 — LAN multiplayer and live photo mode

Download `Tuin-Doom-Enhanced.exe` below. Older releases remain available.

## LAN multiplayer

- In-game hosting and LAN game browser under **F4 > Multiplayer**, styled like the F4 settings.
- Up to four players; hosts can start alone and others can join mid-match. Manual IP joining is also available.
- Matching build, IWAD and add-ons are checked before joining. Fluid Weapons settings follow the host.
- **Q weapon wheel** works without slowing the multiplayer game.
- Synchronized vertical aiming and selectable Green, Gray, Brown or Red player colours.
- Host-selectable co-op friendly fire, including teammate splash damage and knockback protection when disabled.
- **F8 live photo mode** with orbit, zoom, subject selection, depth of field, colour filters and **F7 screenshots**, without pausing the match.
- Bounded command history, network buffers and catch-up work to limit memory growth.

Both PCs must use this release and the same IWAD/add-ons in the same order. See [LAN instructions](https://github.com/tuin-boop/Tuin-Doom-Enhanced/blob/main/launcher/LAN-MULTIPLAYER.md) in the repository. LAN uses TCP 5031 and UDP 5032.

Destruction, door blowouts, FluidMonsters, custom AI and lockdowns are disabled in multiplayer. Photo frame stepping and automatic freeze triggers are single-player features. This does not add general ZScript mod support.

## Included single-player updates

This package also includes the recent photo-mode, door destruction/shield, arena-lockdown and Fluid Weapons presentation work. Existing Camera Director, arcade scores, coloured destruction and optional VoxelDoom support remain available. VoxelDoom and commercial IWADs are not bundled.

All **29 regression tests passed**, including shader compilation.
