# Camera Director, arcade scores and smoother weapon wheel

Download **Tuin-Doom-Enhanced.exe**, run it, and select your own IWAD. Commercial game data is not bundled. Older releases remain available.

## Camera Director (F9)

- Place green camera markers on walls before recording a run. Cameras track the player during playback and switch to a nearby viewpoint.
- Save camera layouts per level, remove the last camera, or clear the layout. Older takes use the current camera layout, including cameras added later.
- Browse and replay takes for the current level; delete individual takes with confirmation.
- Playback hides gameplay popups and HUD elements and uses a steady camera without player view bob.
- Manually stopping a recording asks for confirmation. Finishing the level saves the take and returns to the main menu.
- Stopping playback returns to first-person play at that point in the run.

Takes are engine demos, not exported video files. Replay with the same game data and build; custom gameplay settings can affect replay compatibility. F3 still opens Load Game.

## Arcade / Hall of Fame

- Choose a level for an Ultra-Violence pistol-start score run, with per-level leaderboards and player name entry.
- Animated score feedback, kill/pickup/secret scoring and completion-time bonuses. The three optional AI modes and FluidMonsters are disabled during arcade runs.
- Compact TinyBaby typography, podium artwork and rank effects: rainbow first place, purple second place, silver third place.
- Separate runs using the same name are retained.

## Presentation and gameplay

- Hold Q for the weapon wheel: single-player gameplay slows to 5% while rendering and UI continue smoothly. Actor and moving-sector interpolation now follows the slowed world ticks.
- Toasty can trigger once per level, randomly on the first, second or third eligible gib. Its existing toggle remains available.
- Optional keycard/skull pickup hand presentation with lighting, selectable helmet mugshots and improved HUD spacing.
- Customizable hold-to-peek controls, refined aiming alignment and weapon-wheel artwork.
- Additional monster collision/ledge recovery fixes.

## Validation

Native checks passed for Camera Director placement, layout persistence, replay movement/aim/shooting, take deletion, stop confirmation and level-exit behavior; weapon-wheel selection and slowed interpolation; and Toasty's once-per-level random trigger.
